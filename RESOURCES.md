# SensorLab: Reference Resources

Projects found during search. These are references to read and learn from, not parts of the plan.
Check each repository's license and activity before copying any code.

## Phone sensors over WebSocket

- https://github.com/umer0586/SensorServer: Android app that streams phone sensors over WebSocket. Multiple clients.
- https://github.com/tvogels/accelerometer-stream: browser-based motion streaming to a server over WebSocket.
- https://github.com/priyankark/SensorStreamServer: Python companion server for a phone sensor app (MIT).
- https://github.com/priyankark/phonepi_sampleserver: Node and Python sample servers for a phone sensor app.

## 3D dashboards and digital twins (Three.js)

- https://github.com/exploring-solver/scadaverse-cranedashboard: Three.js scene, WebSocket listener, mock SCADA data generator (MIT).
- https://github.com/PROGRAMIK9/XR_EL: Three.js twin that maps live IoT telemetry onto 3D components.
- https://github.com/game4automation/realvirtual-WEB: browser 3D HMI and digital twin viewer (AGPL-3.0, copyleft).
- https://github.com/hawk86104/three-vue-tres: Three.js, Vue 3 and TresJS framework for digital twins.
- https://github.com/3mapslab/3digitaltwin: WebGL starter kit for IoT projects (MIT, last updated 2023).
- https://github.com/microsoft/iot-cardboard-js: React component library for IoT 3D viewers (not checked directly).

## Electron and Three.js desktop apps

- https://github.com/dartignan/lithium: 3D model viewer with Electron, React and Three.js, with installers.
- https://github.com/tpjnorton/weathr: 3D weather app on desktop with Three.js.
- https://github.com/qti3e/slye: desktop 3D presentation app with Three.js (MIT).
- https://github.com/shanavaskv/crystella: early-stage Electron and Three.js visualization.
- https://github.com/CubeVi/3DMonitor: Electron app driving a light-field display (Apache 2.0).

## Arduino UNO Q and board-side projects

- https://github.com/philippe86220/uno-q-sensors-webui: Modulino sensors read on the microcontroller, sent to Python over Bridge, shown in a web dashboard.
- https://github.com/arduino/app-bricks-examples: official App Lab examples (MPL-2.0).
- https://github.com/arduino/docs-content: Arduino documentation source.
- https://github.com/eigen-value/app-bricks-examples: fork of the examples repository.
- https://github.com/CWTI-Ltd/arduino_uno_q_knowledge_base_and_playground: community knowledge base and playground (not official).
- https://github.com/avnet-iotconnect/iotc-arduino-uno-q-app-lab: App Lab demos sending telemetry to an IoT platform.

## Simulators and fake sensor data

- https://github.com/sohooo/droneops-sim: drone telemetry simulator in Go, with replay mode.
- https://github.com/radevgit/iosynth: general IoT device and sensor simulator.
- https://github.com/iotmertech/iot-data-generator: Rust CLI generating sensor payloads over MQTT, HTTP or TCP.
- https://github.com/ntrp/iot-simulator: pluggable IoT simulator in Rust.
- https://github.com/proarsing/simulators: IoT and Industry 4.0 simulators in Go.
- https://pypi.org/project/faketelemetry/: zero-dependency Python fake telemetry generator.
